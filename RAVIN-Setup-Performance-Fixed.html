FAQ

Pertanyaan sebelum order.

Bisa request software tertentu?

Bisa. Sebutkan software yang kamu butuhkan, termasuk software Adobe bila diperlukan. Kami bantu cek apakah software tersebut bisa dipasang pada laptopmu.

Apakah semua laptop bisa?

Belum tentu. Instalasi bergantung pada spesifikasi dan sistem laptop. Kami cek sebelum pemasangan.

Bisa install beberapa software sekaligus?

Bisa. Gunakan SCHOOL READY, DKV READY, atau FULL SETUP sesuai jumlah dan kebutuhan software.

Kalau saya tidak tahu nama software yang dibutuhkan?

Sebutkan jurusan dan kebutuhan tugasmu. Kami bantu mengarahkan software yang relevan untuk dibahas sebelum instalasi.

Bagaimana proses dan waktunya?

Laptop bisa diantarkan atau diserahkan saat ketemuan. Waktu dan lokasi disepakati terlebih dahulu. Lama pengerjaan tergantung jumlah software dan proses instalasi, lalu dikonfirmasi setelah kebutuhan diketahui.
